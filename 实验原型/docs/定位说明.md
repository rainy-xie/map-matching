# 第一版定位模型：候选坐标与离线序列推断

实现入口是 `gpsmap.inference.infer(observations, spatial_map, config)`。它只接收观测、地图接口和参数，模块不打开文件，也不导入评测或参照生成代码。参照由评测模块单独使用。每条观测得到一个带时间戳的估计坐标；坐标来自候选格网中心，所以第一版仍有格网量化误差，并不是对连续坐标进行任意精度优化。

假设某一时刻 GPS 落在障碍边缘，地图接口在观测周围搜索有限半径，返回允许或属性未知的候选格网中心。观测评分偏好更接近 GPS 的候选。随后查询前后候选的图最短路长度：直线相近但被障碍隔开的两个点，可能需要绕行；如果在真实的时间间隔内无法以设定最大速度完成该绕行，转移被拒绝。Viterbi 保留通往每个当前候选的最佳累计评分和前驱，最后从整段末尾回溯，得到各时刻的坐标。允许一次转移跨过多个格网单元，不把“相邻时刻”误解为“只能移动到相邻格子”。

## 评分定义与假设

观测为二维位置 $z_t$，候选为 $x_t$，观测输入的 `sigma_m` 是合成噪声的每轴标准差。观测对数密度为

$$\ell_o(x_t,z_t)=-\frac{\|x_t-z_t\|^2}{2\sigma_t^2}-\log(2\pi)-2\log\sigma_t.$$

两个时刻相隔 $\Delta t$ 秒，地图图路径长为 $d_G$ 米；如果路径不可达或 $d_G/\Delta t > v_{max}$，转移评分为负无穷。其余转移评分为

$$\ell_m(x_{t-1},x_t)=-\frac{1}{2}\left(\frac{d_G}{s_v\Delta t}\right)^2.$$

这里的 $s_v$ 对应 `motion_sigma_mps`，默认 3 m/s；最大速度默认 8 m/s，都是待校准的工程假设。该随机游走先验偏好较小移动，能抑制观测跳动，也可能把真实运动幅度压小、把停留与缓慢移动混淆。它不是已测得的运动员速度分布，没有加入未知地表速度或坡度，也未把从同一 GPS 差分得到的方向当作独立传感器信息。

转移势没有按每个前驱的后继集合做概率归一化。因此本实现准确的名称是 **HMM 风格的最大路径评分基线**：保留候选状态、观测似然、运动转移和 Viterbi 结构，但不能把累计分数当作规范化 HMM 概率或可靠置信度。它也没有把完整候选集合外的位置作为隐藏状态，搜索半径与 K 截断会影响可找到的路径。诊断字段明确保存 `transition_normalized=false`、`score_is_calibrated_probability=false`。

动态规划采用

$$D_t(j)=\ell_o(j,z_t)+\max_i[D_{t-1}(i)+\ell_m(i,j)].$$

初始候选使用相同先验，直接以观测评分初始化。每步减去该步最大分数，保证长序列数值稳定；同一步减去常数不会改变最优路径。候选按距离及节点编号稳定排序，完全相同的评分选排序靠前者，确保复现。

本版读取整段观测再回溯，未来观测能够改变过去位置。它是离线轨迹纠正原型，不能据此声称提供实时定位。自动测试专门检查了未来观测改变首点的情形。

## 输出与失败处理

`map_only` 使用相同候选接口和观测评分，每个时刻独立选择候选，不查询运动连接。它用于区分最近候选吸附与加入时序约束的效果；原始 GPS 仍须作为另外的对照。两个接口都返回估计序列和诊断字典，不输出精度结论。

输出状态 `ok` 只表示候选与该步连接通过当前实验约定，不代表位置正确。涉及未知通行性的候选或已选连接标为 `map_unknown`，路径可用于计算但不能据此宣称现实中可通行。无候选时保留原始 GPS 坐标，标 `no_candidates` 并结束前段。若当前所有候选都无法从前一时刻转移，先回溯保存前段，再以当前观测重新开始，当前点标 `reset_unreachable`。这不是成功的跨段运动推断，轨迹绘图和评价应保留其断点或警告。

状态字段只能表达一个主要状态，重启标志优先于未知标志；诊断里的 `unknown_path_indices` 仍记录涉及未知的输出下标。诊断还记录无候选下标、重启下标、片段数、候选总数、连接查询次数、速度与不可达拒绝数量。没有失败标记也可能比原始 GPS 误差更大，评测不能因此只选择 `ok` 样本。

空输入返回空序列；非有限坐标、非正噪声与参数、重复或倒序时间均拒绝。每条输入输出一一对应，非等间隔采样逐步使用实际时间差。候选数最多 K 时，推断评分需要约 $O(TK^2)$ 对候选检查，回溯内存为 $O(TK)$；地图最短路查询的额外代价由地图实现和缓存决定。
