# 接口、最小实验与文件分工 v0.1

冻结时间：2026-11-01，首次运行前。所有依赖、共享类型、配置和命令入口归主代理维护。当前实际并发槽位为四个（含主代理），使用地图、定位、评测三个子代理，不继续派生。

第一条开发样例使用 200 × 160 m 合成平面、4 m 均匀格网、明确设定的障碍，以及人工定义折线和停留段生成的参照。按时间插值得到参照坐标，然后用独立固定随机种子加入观测噪声。参照构造不调用地图最短路或 HMM。先以一条绕障碍轨迹联调，再运行自由离路、停留、狭窄通道、开阔地弱约束、错误地图等全部预设场景和三个种子。低噪声开阔地用于暴露格网量化造成的退化，不把所有实验都设计成模型获益。

同时裁取真实丰台地图局部，WGS84 元数据转换到 UTM 50N，再减去记录在 metadata 中的局部原点；所有距离以米计算，时间为相对起点秒，严格递增，允许非等间隔。真实样区保留道路、植被、水系的来源，通行性均为 unknown。在它上面生成的轨迹仍标为 synthetic_on_historical_map；既不声称路径现实可走，也不声称坐标已经实地配准。

## 数据和函数契约

地图为 JSON：`name, bounds=[xmin,ymin,xmax,ymax], crs, source, background={passability,source}, features`。每个 feature 使用 GeoJSON Feature（Polygon/MultiPolygon/LineString），properties 至少含 `kind, passability, source`；allowed/blocked 仅用于有依据或明确实验假设的面，真实地图一律 unknown。背景 unknown 不等于 allowed。不得读取或复制服务点个人信息。

`GridMap(spec, cell_size_m)` 位于 spatial.py，以格网单元中心生成有限候选坐标。`spec` 保存输入，`nodes` 为 Candidate 序列。`candidates(x_m,y_m,radius_m,max_candidates)` 按距离、node_id 稳定排序；只返回圆内最近最多 K 个候选，范围外返回空，不自动扩搜索范围。格网是第一版可解释基线，并非创新剖分或连续优化算法。

`connection(a,b)` 返回 Connection(status,distance_m)，通过八邻接格网图最短路连接；边需做障碍相交检查，不能斜切障碍。reachable 表示已设定通行空间，unknown 表示路径涉及未知通行性，unreachable 表示图内不连通。未知路径可供推断计算，但不能解释成已证实可走。可跨多个格网单元，距离不是只检查单步邻接。`statistics()` 至少给出节点、无向边数量、分辨率。`export_regions(path)` 输出带来源属性的网格 GeoJSON。边界穿越、格网无法表示窄通道属于明确近似局限。

`prepare_map.build_real_sample(gpkg_path, output_dir, cell_size_m=8.0)` 读取已有 GPKG，确定一个同时含道路/植被/水系的小区域，输出 `fengtai_map.json`、`fengtai_regions.geojson`、`fengtai_preview.png`、来源和范围记录；返回地图 JSON 路径。不得修改输入。样区目标约 400 m 见方，选择规则固定并记录。

观测 CSV 仅 `t_s,x_m,y_m,sigma_m`，sigma 为每轴高斯标准差（合成设定，不冒充设备 accuracy）。参照 CSV 单独位于 `reference/trajectory.csv`，列 `t_s,x_m,y_m`，禁止定位模块读此目录。`infer(observations, spatial_map, config) -> (list[Estimate], diagnostics:dict)`；`map_only(observations, spatial_map, config)` 同样返回二元组，作为无运动评分对照。输入契约见 contracts.py。输出坐标每时刻一条，包含 region_id、status、candidate_count；原始 GPS 对照直接使用原始坐标。

HMM 观测评分为各候选到 GPS 的二维高斯对数似然；转移使用图上距离和时间差，超过最大速度或不可达为不可能，其余采用零均值随机游走的二次移动代价。所有速度尺度为待校准假设。使用对数域 Viterbi 整段离线解码，未来观测可影响过去估计，不能称在线算法。转移代价为非归一化势函数，与高斯观测组合形成 HMM 风格的最大路径评分，不输出校准置信度；为便于解释，此版本不混入从同一 GPS 派生的方向作为独立观测。

无候选时回退原始 GPS 并标 no_candidates，结束当前可解码段。所有转移不可行时结束前段，从当前时刻重新初始化并标 reset_unreachable。未知地图输出 map_unknown；解码成功但误差更大同样保留，不能以失败标志筛掉困难点。严格拒绝 NaN、重复/倒序时间及非正参数。

`evaluation.generate_suite(output_dir, config, fengtai_spec=None) -> list[Path]`：每个数据集目录下写 `map.json, observations.csv, reference/trajectory.csv, metadata.json`。metadata 记录 scenario、seed、label、噪声/轨迹生成假设、cell_size_m。同种子生成结果应一致，已存在输出目录不覆盖。`evaluate_run(dataset_dir,prediction_csv,output_dir,method_name) -> dict` 保存逐点误差及统计；`plot_comparison(dataset_dir,predictions:dict[str,Path],output_path)` 绘制参照/原始 GPS/各方法并标合成。误差包含所有时刻、RMSE/均值/中位数/P95/最大值，另报状态分布；不能只报成功片段。耗时由主运行器对地图构建、纯推断、评测分别计时。

数据流：人工路线与独立噪声生成 → 观测文件 → 地图候选与连接 → 评分/Viterbi → 逐时刻坐标；参照文件仅进入最后的评价和绘图。CLI 推断作为独立子进程运行，只接收观测、地图、配置和输出路径。复现实验另外核对同输入坐标/状态文件一致，计时不要求逐字相同。
