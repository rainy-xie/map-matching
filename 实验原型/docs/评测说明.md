# 合成数据与评价 v0.1

评测代码在 `gpsmap/evaluation.py`。所有参考路线均直接由人工指定的时刻—坐标关键点插值或解析曲线生成，没有调用地图图搜索、最短路或定位模块。先得到参照，再在每个时刻加入独立二维高斯噪声；模型输入 CSV 只包含时间、带噪坐标和每轴噪声标准差，参照单独保存在 `reference/trajectory.csv`，由评价器在推断结束后读取。这样可以检查模型如何利用地图和时序约束，但不能替代真实 GPS 与独立测量参照的实验。

全部场景、路线和噪声在首个模型结果之前固定于代码，默认配置指定三个随机种子。每个场景与种子使用 `SeedSequence([seed, scenario_index])` 建立独立 PCG64 随机流；同一场景的参照不会随噪声种子改变。数据文件不写入当前时间，完全相同的配置会生成逐字一致的 CSV 与 JSON。输出目录已存在时拒绝覆盖。变更场景、参数或代码应提升版本并保留旧结果。

| 场景 | 固定机制 | 观测与参照的区别 |
| --- | --- | --- |
| obstacle_detour | 200 × 160 m 空间内绕过已设定矩形障碍 | 人工关键点从障碍上方经过；默认每轴 6 m 高斯噪声可能把 GPS 推入障碍 |
| free_offroad | 沿解析正弦曲线合法离路移动，采样间隔按 1.5、2、2.5 s 循环 | 图上装饰道路不强迫人贴路；检验非等间隔输入 |
| stop_and_go | 人工规定在 45—85 s 停留 | 参照静止时 GPS 仍有噪声，检验时序约束 |
| narrow_passage | 穿过宽 16 m 的人工通道 | 通道只有四个标称 4 m 格网宽，暴露剖分与候选覆盖敏感性 |
| open_low_noise | 没有有用边界的开阔地，观测每轴噪声仅 0.35 m | 该噪声低于格网分辨率，量化后的坐标可能明显更差 |
| wrong_map | 参照世界是空地，模型地图中故意加入不存在的障碍 | 人工制造地图错误；绕行、重启、回退和误差增加均完整记录 |
| fengtai_historical（可选） | 在真实历史底图范围内放置解析曲线 | 地图未知通行性保持 unknown；路线是否现实可走、底图是否配准均未验证 |

每条路线有 71 个时刻，前六类持续约 140 s，丰台底图场景持续 210 s。真实地图场景标签为 `synthetic_on_historical_map`，其他为 `synthetic`，全部叠图都明确显示 SYNTHETIC。一般场景的合成背景 allowed 是实验设定，不能类推真实空白地物可通行。错误地图场景的障碍只存在于模型输入，图注与 metadata 明确指出这一点。

当前噪声只有独立各向同性高斯，未覆盖 GPS 的相关偏差、多路径、系统漂移或长缺测，因此结果不能外推到所有设备和环境。场景集是机制检查集，没有在上面自动调参，也不把这六条人工路线称为独立真实测试集或泛化证据。后续需要独立路线、其他噪声模型、参数敏感性及真实参照实验。

评价首先核对每个时刻一一对齐，拒绝缺行、重复/倒序时间、非有限值。逐点欧氏误差使用同一局部米制坐标；对全部时刻计算 RMSE、均值、中位数、线性插值的 P95 与最大值。时间间隔不均匀时仍是“每观测点等权”统计，并非时间加权积分。原始 GPS 使用原始坐标，不做额外平滑或筛选。

无候选回退 `no_candidates`、断连重启 `reset_unreachable` 都保留在误差分母，并另报状态计数与 failure_count。`map_unknown` 说明通行性未确认，不代表数值推断失败。成功状态的点也可能比原始 GPS 更差，不能用状态筛掉困难点。评价输出 `{method}_errors.csv` 与 `{method}_metrics.json`，纯推断、地图构建和评价耗时由主运行器测量，不能把绘图耗时冒充定位延迟。

轨迹图左侧叠加合成参照、原始 GPS、各预测及可见失败标记，右侧显示所有时刻误差。无候选回退点的前后、断连重启点的前一条线段不连接，防止把断链显示成合法轨迹；其坐标仍以红色叉号保留。一般相邻估计点的连线只是采样坐标之间的弦，不是地图最短路的几何复原，因此不能用它单独判断完整行进路径是否合法。地图障碍只代表模型中的假定障碍，真实底图多边形以浅色/纹理提示属性未知。横纵坐标为米、时间为秒；绘图用英文图例避免跨平台中文字库导致缺字，正文说明为中文。

联调时修复了一处表示不兼容：free_offroad 的装饰道路线不具备面宽度或面通行证据，其 passability 改为 unknown；合成背景仍按原设定 allowed。此修复没有改路线、观测噪声、随机种子或模型参数，也没有把未知线转换为禁行障碍。测试新增了全部六类地图都能通过共享 GridMap 构造的验证。

独立验证使用 `python -m unittest discover -s tests -p test_evaluation.py -v`，覆盖确定性生成、不同噪声种子下同一参照、观测中不包含参照列、正常场景不穿障碍及错误地图刻意相交、手算误差与失败点保留、时间/NaN拒绝、真实地图未知标签及 PNG 输出。它们检验评价程序本身，不把测试通过当成算法精度已得到证明。
