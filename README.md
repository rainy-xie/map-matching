# 地图与运动约束辅助 GPS 轨迹纠正

本仓库保存毕业设计的研究文档、阅读笔记，以及地图与运动约束辅助 GPS 定位纠正实验原型。研究重点是将地图空间表示、候选位置和运动约束结合起来，估计带噪声观测对应的位置序列。

当前原型为 **v0.1.0，离线、合成数据实验**：已实现均匀格网候选、地图连接查询、HMM 风格 Viterbi 推断，以及原始 GPS、仅地图、地图与运动约束三种方法的评测。正式记录包含 7 类场景 × 3 个噪声种子，共 21 条轨迹，每条 71 点。

**目前尚无真实运动员 GPS 和独立实测位置参照。** 丰台场景使用历史地图几何与合成轨迹，通行性和现实配准仍未验证；实验中既有改善，也有退化。现有结果不能作为真实定位精度提升或改进剖分有效性的结论，最终论文范围仍需导师确认。

## 克隆后运行

已验证的开发环境是 macOS arm64、Python 3.12。先克隆仓库，在实验原型目录安装固定版本依赖：

```sh
git clone git@github.com:rainy-xie/map-matching.git
cd map-matching/实验原型
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m unittest discover -s tests -v
./run.sh runs/my-reproduction
```

输出目录必须是新目录，脚本会拒绝覆盖既有结果。一次完整运行会生成 21 条合成轨迹及其评测、耗时和叠图；输入保存在 `datasets/`，结果保存在 `results/`。新运行默认被 Git 忽略，需要归档时应有选择地调整忽略规则。

仓库包含运行所需的丰台小范围地图样本，执行合成实验无需老师的完整原始地图。重新裁切该样本或重建完整 GeoPackage 则需要本地原始资料。

## 同步范围与复现边界

仓库保留源码、配置、依赖清单、研究与核查文档、文献题录和个人阅读笔记，以及一份完整的正式运行 `实验原型/runs/2026-11-02-v0.1-verified/`。正式运行中的合成输入、逐点预测、指标与图像一并保存，失败和退化结果也保留。

虚拟环境、缓存、早期联调、重复运行、文献 PDF 与全文提取、老师原始压缩包和解包目录、完整派生地图及个人开题报告由[忽略规则](.gitignore)排除。这些文件继续保留在本地。文献可从题录中的来源链接获取；历史文档中指向这些本地附件的链接，在 GitHub 上不会有对应文件。

`release_manifest.json`、`verification/` 和运行环境记录保留的是 2026 年 11 月 2 日的验收证据，其中可能含原工作目录的绝对路径及当时尚未建立 Git 仓库的描述。为保留证据，未将这些历史记录改写为本次同步后的状态。原有 `verify.py` 同时检查全部原始资料哈希，因此仅凭本仓库克隆不能完成它的全部检查；需要恢复本地原始资料并另行生成重复运行。

接下来的研究工作是补充无地图的运动约束对照，分析量化、地图与运动先验的贡献，再检查候选预算、网格尺度和改进剖分方案。真实数据采集和独立参照的落实仍是后续任务。
