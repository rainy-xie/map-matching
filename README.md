# 定向越野区域剖分、剖分运算与定位纠正

日常从这里进入两份主文档：[研究方案](研究方案.md)说明论文研究什么及其边界；[研究进度与接力说明](研究进度与接力说明.md)记录做到哪里、下一步做什么。

研究按老师明确的三项展开：**区域剖分建立 → 地图与运动员运动特征的剖分运算 → 基于知识化剖分覆盖的定位纠正。** 现有v0.1是离线合成基线，真实运动员GPS和独立实测参照仍缺，具体状态见进度文件。
